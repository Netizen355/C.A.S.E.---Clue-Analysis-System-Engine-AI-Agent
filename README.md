THIS VERSION IS INTENDED TO WORK WITH THE SPANISH LANGUAGE; ANY OTHER LANGUAGE MAY NOT WORK AT 100%. This is a Proof of Concept (PoC) of a project of an Analysis System AI agent for detectives/police. CASE's only objective is to explain the information provided by the user in a more comprehensive way and then only deduct from the information given. CASE will always try to give 4 types of information: Suspects, Non Suspects, Schematic Chronology and Key Following Questions. CASE has 5 levels of reliability: (Very Low, Low, Moderate, High, Very High); they indicate the strength of the deduction. CASE is NOT BIASED by any means (or at least it has been designed to be so). CASE WILL NOT give final answers as "The murderer is ...", it will just give deductions and direct conclusions (or not so direct, but then the reliability factor will always appear).
